# Manifest and provenance

This reviewer package was assembled from the following supplied archives:

1. `ntable-shared-topology-incremental-experiment-complete(1).zip`
   - used as the authoritative current N-Table + Pratt + Shared-Reuse implementation;
   - contributes the 3,000-expression RQ3 dataset and archived RQ3 results.
2. `RQ3_Structural_Reusability_Jupyter_Package(1).zip`
   - contributes the Jupyter notebook, plotting script, and archived RQ3 figures.
3. `jss_baselines_python38(1).zip`
   - contributes the independent AST-EP and HT-EP paper-based reconstructions.
4. `ntable-python-py38-pratt-baseline(2).zip`
   - only non-obsolete Pratt/Python-compatibility documentation is retained;
   - its earlier D-only RQ3 implementation is deliberately excluded because it is
     superseded by the current shared-topology experiment.

Interpreter cache directories (`__pycache__`) and `.pyc` files were removed.
